# 03 — Domain Guides (how each recurring product works)

**Pre-market brief (08:30 ET, Mon–Fri).** Market setup (futures, rates,
overnight news) → what touches the holdings today (earnings, events,
analyst actions, >3% movers with sourced reasons) → pilot account status
(incl. re-reading the trade-approval setting; if approvals are OFF, say so
plainly) → at most 3 actions for the owner, each with move, reason,
playbook-rule citation, and risk-if-wrong. "No action today" is a valid,
common answer.

**Intraday watch (10:30 / 13:30 / 15:30 ET, Mon–Fri).** Trigger-only.
Triggers: a holding ±3% intraday; breaking news on a held name (guidance,
downgrades, lawsuits, M&A); an earnings print due today (pre-print posture /
post-print first read); central-bank decision days (13:30 = pre-decision
posture, 15:30 = reaction after the 14:00 ET decision); the broad index
±1.5%; pilot fills or pilot-limit approaches. No trigger = one line,
"all quiet." A trigger yields a prepared decision with a rule citation —
scheduled runs never trade.

**Close wrap (16:15 ET, Mon–Fri).** Day result (value, $ and %, top movers
with reasons) → pilot status/fills → thesis check with a skeptic pass
(argue against the day's most tempting trade first) → tomorrow's queued
actions (max 3, with invalidation triggers) → scoreboard (pilot vs its
starting value; main unrealized P&L vs cost basis). Fridays add section 6:
weekly rule-firing review + playbook change proposals + ONE
scanner-sourced idea candidate with its open R7 legs evidenced (doc 07,
Playbook R17/R18).

**Monthly playbook review (1st, 17:00 ET).** Regime refresh with dated
sources vs Playbook Section 0; graded scorecard of every desk call
(including the value of doing nothing); pilot vs its benchmark; numbered
playbook change proposals; up to 3 watchlist candidates. Proposals only —
the interactive flow applies changes.
