# Playbooks — reference vs fresh

- `linkedin-overhaul-playbook.md` — TEMPLATE (profile-copy fill-ins).
  The section-by-section method (All-Star, SSI, headline formula, About
  skeleton, settings) with bracketed placeholders where the original
  held one person's approved copy. Fill it in during setup; the result
  becomes your approved profile copy — don't re-apply it blindly after.
- `linkedin-6week-content-pipeline-brief.md` — REFERENCE. The lane's
  founding brief: mission, rhythm, hard rules. Where it conflicts with
  kit docs 03/06/10 (e.g. the digest's old 6 PM / 11 AM slots, the
  topic-options job), the kit docs win — they carry the later decisions.
- `linkedin-idea-backlog.md` — TEMPLATE + KEEP UPDATING. The topic
  pipeline (statuses: backlog → planned → drafted → approved → posted;
  dropped topics stay recorded as dropped — never revive them), the
  standing rules, starter ideas, and the digest design notes.
- `ai-linkedin-voices.md` — CARRY OVER. The voices layer for digest
  research (recent 24–48h takes, substance over follower count). Prune
  and extend it with your own follows during setup.
- `linkedin-week-plan-TEMPLATE.md` — TEMPLATE. The format the Sunday
  calendar job writes every week (standing-context block + day table +
  research notes). The original lane's dated week-plan snapshots were
  replaced by this template in the public edition.
- `workslop-brainstorm-brief-2026-10-20.md` — WORKED EXAMPLE. A real
  brainstorm brief from the original lane (a post the owner later
  dropped — which is itself the lesson: dropped means dropped). Kept as
  the format example for concept-post brainstorms.
