# 11 — Day-One Checklist (LinkedIn Pipeline)

Go-live gate. Every box must pass BEFORE the scheduled jobs are created.
If a box can't be satisfied from this kit alone, the kit is incomplete —
stop and fix the kit first.

## Account & browser
- [ ] Owner confirms the LinkedIn password is saved in THIS account's vault (his word is the confirmation — no test login).
- [ ] Fresh browser profile created ("LinkedIn Fresh"); owner signed in via the native form.
- [ ] Composer TESTED in the fresh profile with a throwaway draft (opens, accepts text, discarded) — before any real compose.
- [ ] Profile spot-check: Follow is the primary button, custom URL + headline match doc 08 / the playbook.

## Workspace
- [ ] Goal tree recreated: `files/`, `tools/` (builders from `scripts/`), `hidden_files/daily-packages/`, `hidden_files/digest-samples/`.
- [ ] Playbooks installed into `files/` (overhaul playbook, pipeline brief, idea backlog, voices, week-plan template).
- [ ] `brand/avatar.jpg` in place (your own headshot, added at setup); builders pointed at it (never any other photo).
- [ ] State seeded: `digest-edition.txt` = 1 on a fresh setup (worksheet); empty `linkedin-queue.json` + `engagement-log.jsonl`.
- [ ] Playbooks + idea backlog reviewed — dropped topics (e.g. workslop) and standing decisions are known.

## Manual test cycle (nothing publishes)
- [ ] One digest built by hand: research sweep → spec → poster render → 8 pages verified → EVERY slide PNG-inspected (cover + recap included) → package saved. Left as a draft.
- [ ] One concept-post package finalized by hand (copy + asset + first comment) and presented with the `schedule` / `edit:` / `skip` close.
- [ ] Carousel bullet-length check demonstrated (≤ ~125 chars, last bullets visually verified).
- [ ] Owner reviews both packages and approves job creation.

## Go-live
