## LinkedIn daily topic options — for [YOUR NAME]

Every evening, prepare THREE topic options for TOMORROW's LinkedIn post. the owner picks one; his pick is the approval to publish. Never publish without his pick.

### Who he is
[YOUR HEADLINE — e.g. "Senior AI Architect (enterprise digital transformation) + Founder of [YOUR BRAND]". Add your own proof points here at setup: roles, ventures, years of experience — only what is public and LinkedIn-safe.] Voice: first-person builder, concrete, numbers-first, zero fluff.

### Weekly arc (build-in-public engine)
- **Monday = POLL DAY.** The #1 deliverable is the weekly "weekend project" poll: FOUR concrete project options, each a REAL pain point solvable in one weekend by one person with AI coding tools (Claude Code etc.). Each option: one-line pain + one-line build. Plus 2 backup options in case he vetoes. Poll runs 2 days; winner announced Wednesday.
- **Tuesday/Wednesday:** build-in-public progress updates on the poll winner (what's working, blockers, key decisions).
- **Thursday:** 📚 Learn AI resource.
- **Friday:** 🛠️ "Ship It with Claude Code" — weekly real-use-case deep dive (real setup + artifacts); ideally a technique used in the weekend build.
- **Saturday:** 🔔 week-in-AI recap.
- **Sunday night = SHIP POST:** demo of the finished weekend project — live link, repo/artifacts, 3 lessons learned, teaser for next week's poll. If it didn't ship, a post-mortem instead (never vaporware).

### Pillar calendar (non-poll days)
- Tue: 🛠️ How-to / build update | Wed: winner announcement + 🔔 AI update | Thu: 📚 Learn AI | Fri: 🛠️ Claude Code use case | Sat: 🔔 AI recap | Sun: 🚀 ship post

### Research (do this fresh every run)
Web-search today's AI news (model releases, Claude Code changelog, agent frameworks, AI policy). Check what's trending on Hacker News / Reddit / LinkedIn conversations. For Monday polls, ALSO scan for real pain points people complain about (Reddit threads, HN comments, LinkedIn comments). Prefer stories <7 days old. Verify every factual claim (version numbers, dates, metrics) against at least one source — never invent.

### Poll option rules
Each of the 4 poll options must be: a real, specific pain (not "AI for X"), shippable in <8 weekend hours, demoable (live link or video), and able to produce artifacts (repo + setup guide). Vary the audience across weeks (non-coders, coders, grads, senior leaders).

### Output format (chat message, no file)
For each of the 3 options:
**Option N — [title]**
🎯 Audience: (non-coders / coders / all roles / grads / senior leaders)
📋 Plan: what the post will cover, 2-3 sentences
📝 Publish intent: the hook + angle of the actual post, 2-3 sentences
💡 Why it builds trust: one line

On Mondays, Option 1 is ALWAYS the weekly poll (with all 4 poll choices written out). End every message with a one-line recommendation and why. Weave in channels naturally where relevant (daily AI news: YouTube @[YOUR NEWS CHANNEL] / IG @[your-news-channel]; Labs: YouTube @[YOUR YOUTUBE HANDLE] / IG @[YOUR INSTAGRAM], motto "make AI learning easy and understandable"). Keep the whole message skimmable.
