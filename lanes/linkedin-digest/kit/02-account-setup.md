# 02 — Account Setup (LinkedIn Pipeline)

## 1. The LinkedIn account (existing — connect, don't recreate)

- Profile: [YOUR NAME], [YOUR LINKEDIN URL]. Work through
  `playbooks/linkedin-overhaul-playbook.md` first if your profile needs
  the overhaul (headline, About, banner, custom URL, "Make follow
  primary" ON — visitors see Follow, Connect sits in More); the filled
  playbook then holds your approved copy if anything ever needs
  re-applying or auditing.
- Login: native LinkedIn email + password form, email
  `[YOUR EMAIL]`, password from the owner's Secure Vault.
  - Keep ONE vault entry for LinkedIn and treat your most recently
    updated entry as the working path. If older notes describe an entry
    as untested, do not "fix" it, and never attempt the login
    autonomously.
  - "Sign in with Google" is NOT the path (the saved Google password was
    rejected). Use the native form.
- SSI target 70+ (linkedin.com/sales/ssi); Premium is for InMail +
  profile-view depth, it does not change All-Star/SSI formulas.

## 2. The browser profile — "LinkedIn Fresh" (critical)

- The OLD default browser profile's LinkedIn editor is corrupted at
  profile level: composer, repost, and comment boxes fail with "There
  was a problem loading the content" while feed/messaging read fine.
  Verified NOT a CAPTCHA, NOT an account or IP block.
- **Setup step:** create a FRESH named browser profile for LinkedIn,
  sign in there (owner present for credentials/approvals), and TEST THE
  COMPOSER with a throwaway draft BEFORE composing anything real.
- **Standing rule:** ALL LinkedIn browser work uses the fresh profile
  until the default profile is repaired or replaced. If a session shows
  no page-level progress within minutes, stop, close it, and check the
  actual window/tab state before spawning more sessions.

## 3. Medium (research input)

- The digest research sweep includes a signed-in Medium pass ("For you"
  feed + the artificial-intelligence tag) on the shared browser profile,
  which holds the owner's Medium session. If the session is absent on
  the new account, the owner signs in once; the sweep notes honestly
  when the Medium pass was skipped (past runs have done exactly that).

## 4. Verification pass (before any content work)

- [ ] Fresh profile created; LinkedIn feed loads; composer opens and
      accepts text in a throwaway draft (then discard the draft).
- [ ] Profile shows Follow as the primary button; custom URL correct.
- [ ] Vault login path confirmed BY THE OWNER (he says it's saved; the
      agent does not test-login).
